# M6: 検索・リンク・アーカイブ

完了日: 2026-11-06 / ブランチ: `codex/search-links-archive`（M5から派生）

SQLite FTS5のtrigram検索を追加した。タイトル・本文・概要・タグ・添付キャプション・参照する試料名・プロトコル使用版名と変更点を対象にする。トリガーで同じ保存トランザクション内に索引を更新する。3文字以上はFTS、1〜2文字の日本語や英数字は索引内の本文を部分一致で検査する。空白区切りの検索語はAND扱いで、FTS構文として解釈せずエスケープする。

検索結果は抜粋・所属階層・タグ・日付を持ち、種別、プロジェクト、シリーズ、タグ、期間、状態で絞り込める。本文中のアプリ内リンクを抽出し、手動リンクと区別して更新・削除する。使用プロトコルと試料も被リンクに表示する。

全基本種別でタグ編集、リンク追加、確認付きアーカイブと復元を提供する。アーカイブされた親の子孫も検索・通常一覧・詳細から除外し、アーカイブ画面で継承状態を説明する。親と子の独立したアーカイブフラグを維持する。

検証: 空DBと既存DBへのマイグレーション、型チェック、本番ビルド、単体26件、Chromium E2E 10件が成功。日本語・短い日本語・OD600・試料名・プロトコル名・タグ・写真キャプション、全絞り込み、更新直後の索引反映、本文リンクの追加/除去、アーカイブ配下の除外/復元を確認した。

残課題: M7の整合性バックアップ、復元と性能・運用確認。大幅なデザイン変更は保留。検索結果は最大100件に限定し、絞り込みで対象を狭める。

参照: [SQLite FTS5](https://www.sqlite.org/fts5.html)。
