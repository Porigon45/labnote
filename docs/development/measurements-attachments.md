# M5: 測定表・グラフ・添付

完了日: 2026-11-06 / ブランチ: `codex/measurements-attachments`（M4から派生）

測定表ブロックに系列・時刻（数値）・値・軸名・単位を入力でき、Rechartsの折れ線・散布図と切り替えられる。表示設定と測定値を別のプロパティに保持し、本文の保存と同じトランザクションでMeasurementTableへ同期する。空の測定値はnullで保持する。

画像・ファイルブロックと日次記録の「結果・写真・添付」からローカル保存できる。許可する拡張子からMIMEを決定し、画像・PDF・Office/ZIPは先頭シグネチャも検査する。100MBをストリーム受信中にも制限し、合計10GBはDBの書込みロック内で再検査する。一時ファイルと失敗時の本体を掃除し、UUIDキーで保存する。画像表示、キャプション保存、ダウンロード、MIMEとサイズのメタデータを提供する。

`npm run attachments:audit` は欠損・サイズ不一致・孤立ファイルを報告し、不整合があれば終了コード1を返す。自動削除はしない。

検証: 型チェック・本番ビルド・単体25件・Chromium E2E 9件が成功。OD値を入力した後の表/折れ線/散布図の切替と再読み込み、DBへの数値同期、PNGとキャプションの再表示、未対応形式と503の表示、単体で容量上限と不整合検出・失敗時掃除を確認した。E2EはコンパイルとのCPU競合を避けるため2ワーカー・各60秒以内に設定した。

残課題: M6の全文検索とアーカイブ、M7のバックアップ・容量表示。大幅な外観変更は保留。M3/M4のpushエラーはGitHub APIでブランチを作成してからpushすることで解消し、両ブランチとも反映済み。

参照: [Recharts LineChart](https://recharts.github.io/en-US/api/LineChart/)、[ScatterChart](https://recharts.github.io/en-US/api/ScatterChart/)。
