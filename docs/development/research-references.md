# M4: プロトコル・試料・研究メモ

完了日: 2026-11-06 / ブランチ: `codex/research-references`（M3から派生）

プロトコル・試料台帳・研究メモの一覧、詳細、作成・編集を追加した。プロトコル本文とメモ本文はM3エディタを共用する。プロトコル保存ごとに版を追加し、日次記録では選択した版と変更点を固定表示する。試料は株・プラスミド・プライマー・培地・その他、由来・親試料・作製日・保管場所・状態・備考を持つ。親と派生試料、試料を使用した実験のリンクを表示する。研究メモは計画の5カテゴリで分類・絞り込みできる。

検証: 型チェック・本番ビルド・単体23件・Chromium E2E 8件が成功。試料の作成と派生、使用実験へ戻る操作、使用後に元プロトコルを更新しても旧版と変更点が維持されること、メモ分類を確認。試料の循環が不正な場合に基本情報の編集もロールバックすることを単体検証した。

並列検証でSQLiteの遅延トランザクションにおけるread→write昇格のロック競合を検出したため、保存処理は開始時に書込みロックを取るIMMEDIATE方式へ変更した。

残課題: 測定・添付はM5、横断検索・任意ページ間リンクとアーカイブはM6。既存の緑と白のレイアウトを継続し、大幅な外観変更は保留した。M3のpushはGitHub側の `fatal error in commit_refs_rules` により未反映で、後続段階で再試行する。
